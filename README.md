# EVAVO Vector Studio

A professional local-first vector production platform for converting raster artwork into clean, editable and production-ready vector assets.

## Intended capabilities

- Precision PNG, JPG, WebP and TIFF to SVG conversion
- Logo, icon, illustration and line-art tracing
- Intelligent path simplification without destroying shape quality
- Bézier curve fitting and anchor-point optimisation
- Colour-layer separation and palette cleanup
- Transparency, negative-space and hole preservation
- Stroke and fill reconstruction
- Gradient and mesh-style reconstruction where appropriate
- Geometry cleanup, snapping and symmetry correction
- SVG validation, optimisation and accessibility
- Static and animated SVG output
- Lottie JSON creation, editing, validation and optimisation
- Motion paths, masks, morphing and timeline animation
- Batch processing
- Deterministic CLI and API workflows
- Visual comparison and quality evidence
- Human-editable output suitable for Illustrator, Figma and web production
- Web interface for review, adjustment, animation and export

The goal is not basic automatic tracing. The goal is polished, intentional vector artwork with professional geometry, restrained complexity and reliable production output.
